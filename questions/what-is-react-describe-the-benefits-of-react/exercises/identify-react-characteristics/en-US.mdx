Which statements describe React itself rather than guarantees of a particular framework? Select all that apply.

## Options

### one-way-flow (correct)

Props and context flow down the tree, while updates are requested through explicit callbacks or dispatches.

> This explicit ownership and update path is a core React characteristic.

### component-model (correct)

React lets applications compose UI from components that return declarative element descriptions.

> Components and declarative descriptions are core parts of React’s programming model.

### built-in-router

React core guarantees file-system routing and route-level data caching.

> Routing and data-cache policy are provided by frameworks or libraries, not React core.

### renderer-independent (correct)

React can target environments through renderers such as React DOM and React Native.

> React’s component model is not limited to browser DOM nodes.

### no-build-required

React guarantees that all JSX runs directly in every browser without transformation.

> JSX normally needs a build transform; React itself does not make browsers parse JSX syntax.
